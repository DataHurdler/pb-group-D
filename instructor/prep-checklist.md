# Preparation checklist

Dates count back from the course day (**D**). Fill in real dates once the course
date is set.

## D − 6 weeks: decide

- [ ] Answer every question in [COURSE-BRIEF.md](../COURSE-BRIEF.md)
- [ ] Write the learning outcomes and check each one maps to a module
- [ ] Book venue or platform; confirm capacity, projector, Wi-Fi, power at tables
- [ ] Confirm with the organization's IT team which accounts learners will use
      for Gemini, and whether those accounts are covered by a Gemini license
      (this decides what's safe to paste; see module 03)
- [ ] Confirm the venue network doesn't block gemini.google.com
- [ ] Open registration. Ask about accessibility and dietary needs on the form.
- [ ] Find a co-facilitator if you expect more than 20 learners

## D − 4 weeks: write

- [ ] Fill in "What goes here" for modules 01–04
- [ ] Write every activity sheet from [the template](../templates/activity-template.md)
- [ ] Write the capstone brief and rubric (module 04)
- [ ] Write the pre/post check items ([assessment/pre-post-check.md](../assessment/pre-post-check.md))
- [ ] Decide what learners must install or bring, and write setup instructions

## D − 3 weeks: build

- [ ] Slides for each module (see [materials/README.md](../materials/README.md))
- [ ] Handouts: agenda, activity sheets, capstone brief, action-plan card, quick reference
- [ ] Case and data files for module 03, plus the reference solution
- [ ] Hint cards for activity 3.1
- [ ] **Test the setup instructions on a clean machine**, or ask a colleague to
      follow them exactly. Setup is the most common way a day goes wrong.
- [ ] Set up the feedback form and pre/post check online, if not on paper

## D − 2 weeks: rehearse

- [ ] Timed dry run of every lecture and demo segment out loud. Anything
      over its slot gets cut, not rushed.
- [ ] Work through every activity yourself, as a learner, against the clock.
      Learners usually take 1.5–2× as long as the instructor.
- [ ] Update outlines with what the dry run taught you, then run
      `python3 tools/check_timing.py`
- [ ] Brief the co-facilitator: run sheet, activities, who does what

## D − 1 week: check Gemini

Google changes Gemini often. Run through these on the account type your
learners will use:

- [ ] Every activity and both demos still behave as described
- [ ] **New chat**, editing a sent prompt, and the **Sources** button are where
      the workbook says
- [ ] Saving a prompt works: skills (**Settings → Skills**, or asking Gemini to
      create one) or, on accounts that still have them, **Gems → New Gem**
- [ ] The privacy facts on slide 27 still match Google's
      [Gemini Apps Privacy Hub](https://support.google.com/gemini/answer/13594961)
- [ ] Update the slides, workbook, and module notes for anything that's moved

## D − 1 week: communicate

- [ ] Send the pre-course email ([participants/emails.md](../participants/emails.md))
- [ ] Confirm catering numbers and dietary needs
- [ ] Confirm room layout (tables of 3–4) and AV with the venue
- [ ] Final roster; plan table groups if you want mixed experience levels
- [ ] Note accessibility arrangements in the run sheet

## D − 2 days: print and pack

- [ ] Print handouts (roster size + 10%)
- [ ] Export slides to PDF; copy slides, data, and handouts to a USB stick
- [ ] Print the run sheet and the schedule's trim table

**Packing list**

- [ ] Laptop and charger, presentation remote, spare batteries
- [ ] Video adapters (HDMI, USB-C), and an extension lead
- [ ] USB stick with all materials, plus a cloud copy
- [ ] Printed handouts, run sheet, sign-in sheet
- [ ] Name tents, markers, sticky notes (two colours), flipchart paper, tape
- [ ] Parking-lot sheet
- [ ] Timer (phone works; a visible timer on screen works better)

## D − 1 day

- [ ] Send the day-before reminder ([participants/emails.md](../participants/emails.md))
- [ ] Charge everything
- [ ] Reread the run sheet

## D: course day

Follow [run-sheet.md](run-sheet.md).

## D + 1 day: follow up

- [ ] Send the follow-up email with slides, resources, parking-lot answers
- [ ] Score pre/post checks and summarise (see the assessment file)
- [ ] Read the feedback forms while the day is still fresh

## D + 1 week: improve

Hold a 30-minute retrospective (with the co-facilitator if you had one) and
put the answers straight into the repo:

- Which segments ran over or under? Update the timed outlines.
- Which activity produced the most learning? Which produced the least?
- Which pre/post item moved least? That outcome needs more time or a better
  activity.
- What did the feedback say that you didn't expect?
- What would you cut if you had to lose 30 minutes?
