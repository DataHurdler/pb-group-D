# Pre/post check

The same short check twice: at **9:13** (module 00) and **15:37** (module 05).
Seven minutes each. It's not graded. It shows what the day changed and which
outcome needs more work next time.

## Writing the items

- **6 to 8 items**, at least one per learning outcome
- **Identical** pre and post: same wording, same order
- **Answerable in under a minute each.** Multiple choice, or a short "what would
  you do" answer
- Test **doing**, not recalling. "Which of these would you use when…" or "What's
  wrong with this…", not "What's the definition of…"
- Every multiple-choice item gets an **"I don't know yet"** option, so people
  don't guess and blur the result

## Matching without names

Learners write a **check code** on both sheets: *the last two letters of your
mother's or guardian's first name, plus the day of the month you were born*
(e.g. `NA14`). Pre and post can be matched without anyone's name.

## Learner instructions (top of the sheet)

> This isn't a test and isn't graded. Answer what you can and pick "I don't know
> yet" for the rest; that's expected this morning. You'll answer the same
> questions at the end of the day so we can both see what changed.
>
> Check code: ______

## Scoring (D + 1 day)

For each item, record the percentage correct pre and post:

| Item | Outcome | Pre % | Post % | Change |
| --- | --- | --- | --- | --- |
| 1 | LO1 | | | |
| … | | | | |

- An item that's **high before** (above about 70%) is teaching something people
  already knew. Shorten that part of the course.
- An item that **barely moves** shows an outcome the day isn't reaching. Look at
  the module and the activity that teach it.
- Share the overall change with learners in the follow-up email if it's
  encouraging. People like to see their progress.
